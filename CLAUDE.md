# Taskly

## Purpose

A simple task-management app for students to keep track of things they need to do in school.

## Current Features

- Add tasks
- View tasks
- Edit tasks
- Complete tasks
- Delete tasks
- Save tasks (persisted so they're still there after closing and reopening the app)

## Tech

Plain HTML, CSS, and JavaScript. No frameworks, no build tools, no backend.

## Project Guidelines

- Keep the project beginner-friendly and lightweight.
- Do not add frameworks, databases, login/accounts, notifications, categories, social features, chat, payments, or analytics unless explicitly asked.
- Preserve existing functionality when making changes.
- Test changes before saying they are complete.
- Do not commit or push changes unless explicitly asked.
- Read spec.md before making product changes.
- Keep implementation aligned with spec.md.
- If a requested change conflicts with spec.md, explain the conflict before changing the code.
